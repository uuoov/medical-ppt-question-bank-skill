# 医学 PPT 题库生成与核对

从指定 PPT、PPTX、PDF 或飞书幻灯片生成或核对医学培训题库。默认面向医药企业市场同事，强调能够准确理解和复述产品及疾病领域知识，而不是考查临床决策能力。

## 不可违反的规则

- 只把用户指定的材料当作答案来源。不得凭医学常识、网页、论文或记忆补充事实，除非用户明确授权引入外部来源。
- 每题都必须给出材料页码和能够直接支持答案的证据摘要。没有直接证据时不得出题；核对时标记“证据不足”。
- 题干必须独立、自然，禁止出现“根据 PPT 第 X 页”“按照课件内容”“材料中提到”等暴露来源位置的措辞。页码只写在证据列。
- 图表、截图、流程图、表格和内嵌 Excel 中的数据必须视觉核对；文本抽取结果只能用于定位，不能替代目视确认。
- 不得把讲者备注中的旧数据覆盖正文。正文、图表、正式说明书截图相互冲突时，记录冲突并暂停使用该知识点出题。
- 不得用无业务意义的计算凑题，例如仅计算两个批准日期相差几天；优先考查适应症、疗效、安全性、机制、用法、指南定位和竞争差异。
- 价格、报销、患者援助、获批状态等时效性内容只有在材料标明适用日期且用户接受按该版本出题时才使用。不得把历史政策写成当前政策。
- 交付前必须验证题量、题型、答案字母、选项完整性、证据和重复知识点。未达到用户要求的完整题数不得交付为“已完成”。

## 确定工作模式

### 模式 A：从零生成

适用于用户只有来源材料，没有历史题库、任务表或样例题。

最小输入为：来源材料、单选/多选/判断题数量、输出位置。若只有材料而未给题量，先根据材料信息密度提出一套题量建议并等待确认；不得自行把建议当成最终题量。若连来源材料也没有，说明无法满足可追溯要求并请求材料。

### 模式 B：核对已有题库

适用于用户提供来源材料和现有题库。保持原有三类题量；逐题判断无误、有误、证据不足或待人工确认。修改时必须提供完整可替换文本，不能只写答案字母变化。

### 模式 C：替换过时或不合格题目

保留该题题型和总题量，从材料中选择尚未被其他题目覆盖的知识点重新出题。新题不得只是原题换一种问法，并按生成模式的全部规则校验。

## 开始前的操作

1. 记录来源文件/链接、版本日期、受众、三类题量、输出格式和是否允许写回在线表格。
2. 为本次任务建立独立工作目录，例如当前目录下的 `.medical-ppt-work/<run-id>/`；不把旧缓存当作事实来源。
3. PPTX 先运行 `scripts/extract_pptx_evidence.py` 生成逐页文本、备注和视觉风险标记。PDF 或在线幻灯片使用当前环境对应的 PDF、演示文稿或飞书读取能力。
4. 渲染所有包含图片、表格、图表、复杂版式或文本抽取不完整的页面并目视检查。
5. 建立“页码—主题—事实—限定条件—数值/单位—证据原文—视觉确认状态”的证据表，再开始写题。

详细流程见 [generation-workflow.md](references/generation-workflow.md)。题目规则见 [question-rules.md](references/question-rules.md)，核对规则见 [audit-rules.md](references/audit-rules.md)，固定输出结构见 [output-schemas.md](references/output-schemas.md)。

## 从零生成流程

1. 从证据表中筛选具有培训价值、表述明确且无冲突的知识点。
2. 先分配题型和知识点，锁定每类题量，再撰写题目，避免后期靠重复题凑数。
3. 单选题只允许一个最佳答案；多选题至少两个正确选项；判断题使用明确、无双重否定的陈述。
4. 干扰项优先取自同一材料中的其他药物、其他人群、其他数值或条件，并保持语法和粒度一致。不得使用材料外事实作为干扰项。
5. 为每题写出答案为什么正确、其余选项为什么不符合材料。解析不能只是重复标准答案。
6. 输出固定字段：题号、题型、题目、选项内容、标准答案、解析、PPT页码、PPT依据。
7. 将 CSV 结果传给 `scripts/validate_question_bank_csv.py`，并传入用户要求的三类题量。修复全部错误后再交付或写回。

## 核对和修改流程

1. 读取完整题干、全部选项、题型和原标准答案；先固定预期题数。
2. 对照材料逐项检查对象、人群、治疗线数、限定词、否定词、数值、单位、指南名称、推荐等级和时间范围。
3. 对答案字母与选项文本分别验证，防止“答案字母正确但对应文字错误”。
4. 用户提供的问题说明列、批注列或修改方向时，将其视为需要落实的编辑要求；仍需独立补足页码、材料依据和完整解析。
5. 有误时输出原题、问题解析、核对依据，以及修改后的完整题干、全部选项、标准答案和解析。即使只改一个选项，也要给出最终可直接粘贴的完整版本。
6. 若删除旧题并重出，先检查全题库知识点，确保新题不重复。

## 在线表格与飞书写回

- 先读后写。只有用户明确要求更新、写回或补齐在线表格时才写入。
- 优先使用结构化 API/连接器；浏览器仅作为登录态网页无可用 API 时的兜底。
- 账号或 profile 必须由用户、项目规则或当前已验证身份确定，不得在 Skill 中硬编码。
- 写入前记录目标表、工作表和范围；写入后回读表头、首行、中间行、末行、总行数及格式。
- 保持用户原表的列顺序、换行、行高、字体、对齐和间距；若新增结果表，使用 [output-schemas.md](references/output-schemas.md) 的结构。

## 完成标准

- 三类题量与用户要求或原题库完全一致。
- 题号连续且没有重复、遗漏或空题。
- 每题答案均能映射到现有选项，且题型约束正确。
- 每题都有页码和直接证据；视觉型数据已确认。
- 题干中没有 PPT 页码提示，题目之间没有重复考点。
- 修改题给出了完整最终稿和充分解析。
- 在线写回已经回读验证；本地交付文件可以正常打开。
