# 医学 PPT 题库生成与核对 Skill

这个仓库提供一个可安装到 Codex 的 Skill，用于：

- 只有 PPT、PDF 或飞书幻灯片时，从零生成医学培训题库；
- 已有题库时，逐题核对并给出可直接替换的完整修改稿；
- 同时支持单选题、多选题和判断题；
- 强制答案、解析和证据仅来自指定材料，并标注页码；
- 面向医药企业市场同事，优先覆盖产品、靶点、适应症、用法用量、疗效、安全性、指南和竞争格局等知识点。

## 安装

在 Codex 中发送：

```text
使用 $skill-installer 安装这个 Skill：
https://github.com/uuoov/medical-ppt-question-bank-skill/tree/main/skills/medical-ppt-question-bank
```

本仓库默认是私有仓库。使用者需要先获得仓库访问权限，并在本机登录对应 GitHub 账号。安装后如果没有立即显示该 Skill，请重启 Codex。

## 从零出题 Prompt

```text
使用 $medical-ppt-question-bank，根据我提供的 PPT 从零建立医学培训题库。

材料：[PPT/PDF 文件路径或飞书幻灯片链接]
面向对象：市场同事
题量：单选题 X 道、多选题 Y 道、判断题 Z 道
输出位置：[本地 Excel/CSV 路径，或飞书表格链接]

要求：
1. 所有答案、解析和依据只能来自材料，不能补充外部医学知识；
2. 每题必须标注 PPT 页码和可核对的原文或图表依据；
3. 题干不得出现“根据 PPT 第 X 页”“课件中提到”等提示来源的措辞；
4. 三类题目的数量必须与上述要求完全一致；
5. 题目之间不得重复考查同一事实，也不能只是改写句式；
6. 图表、截图或表格中的数值必须目视核对；
7. 输出完整的题型、题干、全部选项、标准答案、解析、页码和依据。
```

如果尚未确定题量，可以先让 Skill 根据培训时长和 PPT 信息密度给出题量建议；确认题量后再生成正式题库。

## 核对已有题库 Prompt

```text
使用 $medical-ppt-question-bank，逐题核对题库与 PPT。

PPT：[文件路径或链接]
题库：[文件路径或飞书表格链接]
输出位置：[文件路径或飞书表格链接]

所有判断只能以 PPT 为依据。发现问题时，请完整写明：原题、问题、PPT 页码与依据，以及修改后的题干、全部选项、标准答案和解析。不要只写“答案改为 B”之类的简略说明。
```

## 最小输入

从零生成时不需要历史题库或任务表，但至少需要：

1. 一份作为唯一事实来源的 PPT、PDF 或飞书幻灯片；
2. 单选、多选、判断题的数量（或先要求 Skill 提出题量建议）；
3. 输出位置。

如果连来源材料也没有，就无法满足“答案完全来自 PPT 且可追溯”的要求，Skill 会先要求补充材料。
